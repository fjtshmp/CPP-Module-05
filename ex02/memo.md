# 抽象クラス
- 共通の設計だけを決めて、実際の処理は子クラスに任せるクラス（継承して使う前提のクラス）。
- 純粋仮想関数を持ち、インスタンス化できない。

# 具象クラス
- 抽象クラスを継承し、インスタンス化できる（すべての純粋仮想関数が実装されている）クラス。

# protected
- 自分自身と、継承した子クラスからはアクセスできるが、外部からはアクセスできない、ことを示すアクセス修飾子

# 例外処理について
- グレードが低い:自作例外
- 未署名：自作例外
- ファイル作成失敗:std::runtime_error
課題で定義されているエラーは自作クラスで処理し、システムエラーは標準ライブラリに用意されている例外クラスを使用。
